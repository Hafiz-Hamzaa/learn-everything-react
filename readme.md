## 💡 Introduction

This repository is created to follow the **ReactJS Full Course | Learn Everything in React**.  
It contains all examples, concepts, and projects explained step-by-step, from **React basics** to **advanced topics** like **Hooks, Routing, Context API, and API integration**.

---

## 📚 Course Overview

The course covers:

- React Overview  
- Import & Export  
- Real DOM vs Virtual DOM  
- Setting Up React with Vite  
- Components & Props  
- Styling with CSS & Tailwind CSS  
- Functions in React  
- Hooks (useState, useEffect, Advanced State Management)  
- Form Handling & Two-Way Binding  
- LocalStorage usage  
- API Calls in React  
- Gallery & Notes App Projects  
- Routing (React Router DOM Basics & Advanced)  
- Context API (Introduction & Practical Use)  
- Children as Props  
- Bonus Concepts
